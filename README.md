# 📈 A股涨停板筛选器 (一进二 + 二进三)

基于 **Streamlit + AKShare（东方财富公开数据）** 的涨停板选股工具。

## 功能

- **模式一 · 一进二**：筛选首板种子选手，五维评分评估二板潜力
  ① 涨停时间与强度 ② 封单质量 ③ 量能与换手 ④ 炸板次数 ⑤ 人气热度与板块效应
- **模式二 · 二进三**：筛选 2 连板标的，四维评分评估三板潜力
  ① 题材强度 ② 量能形态（前缩后放/前放后缩） ③ 位置形态 ④ 资金面与龙虎榜

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

建议在交易日 9:25 竞价结束后运行，或收盘后选择当日日期回看。
首次分析需联网拉取数据（逐股获取历史K线），请耐心等待。

## 说明

- 数据来源：东方财富网（AKShare 公开接口）
- 排除规则：ST、北交所/新三板、科创板；默认股价 ≤ 30 元、流通市值 ≤ 200 亿
- 仅供学习研究，不构成任何投资建议
